# Deploying the website to Cloudflare

The site in `website/` is fully prerendered static HTML served by Cloudflare Workers static assets: no Worker code,
no server, no database. `website/wrangler.jsonc` holds the configuration. Deploying needs the owner's Cloudflare
account; nothing in the repository deploys automatically.

## Build

```bash
./gradlew apiManifest                 # API reference data (build/api/api-manifest.json)
cd website
npm ci
BLOOM_SITE_URL=https://bloom.example.com npm run build
```

`BLOOM_SITE_URL` is the public origin. With it, the build adds canonical URLs and `sitemap.xml`; without it, they are
skipped with a warning. The build fails on broken internal links, missing accessibility basics or inline scripts the
Content-Security-Policy would block, so a successful build is safe to deploy.

Check it locally before deploying:

```bash
npm run preview        # wrangler dev on http://127.0.0.1:8787, with the real _headers and 404 handling
```

## First deployment

```bash
npx wrangler login     # opens the browser; authorises wrangler for your Cloudflare account
npm run deploy         # = npm run build && wrangler deploy
```

Wrangler creates the `bloom-website` Worker and prints its `*.workers.dev` URL. Rebuild with `BLOOM_SITE_URL` set to
that URL (or your domain) and deploy again so canonical URLs are right.

## Custom domain

In the Cloudflare dashboard: Workers & Pages → `bloom-website` → Settings → Domains & Routes → **Add custom domain**
(the domain must be on the same Cloudflare account). Or add it to `wrangler.jsonc`:

```jsonc
"routes": [{ "pattern": "bloom.example.com", "custom_domain": true }]
```

## After deploying

```bash
curl -sI https://bloom.example.com/ | grep -iE "content-security-policy|x-frame-options|cache-control"
curl -s -o /dev/null -w "%{http_code}\n" https://bloom.example.com/does-not-exist     # expect 404
```

The headers come from `dist/client/_headers`, generated by `website/scripts/prerender.mjs`.

## Optional: deploy from CI

To deploy on every push to `main`, create a Cloudflare API token with the **Edit Cloudflare Workers** template, add it
as the repository secret `CLOUDFLARE_API_TOKEN` (plus `CLOUDFLARE_ACCOUNT_ID`), and add a job like this to
`.github/workflows/ci.yml` after the `website` job:

```yaml
  deploy-website:
    needs: website
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    defaults: { run: { working-directory: website } }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/download-artifact@v4
        with: { name: api-manifest, path: build/api }
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: npm, cache-dependency-path: website/package-lock.json }
      - run: npm ci
      - run: npm run deploy
        env:
          BLOOM_SITE_URL: https://bloom.example.com
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          CLOUDFLARE_ACCOUNT_ID: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
```
